# WORSHIP SERVICES ATTENDANCE RECORDS AND ANALYTICS SYSTEM

## 1. Project Description
The Worship Services Attendance Records and Analytics System is a web-based application developed to help the church digitally record, store, manage and view attendance records for worship services.

The system records attendance by gender and age category: men, women and children. It automatically calculates the total attendance for each service.

## 2. Technologies Used
- HTML – Web page structure
- CSS – User interface styling
- PHP – Server-side programming
- MySQL – Database management
- WAMP – Local development environment

## 3. System Features
- User login and authentication
- Attendance recording
- Automatic calculation of total attendance
- Attendance records viewing
- Dashboard displaying attendance statistics
- Logout functionality

## 4. Database Information
Database name: church_attendance (local development database)

Database tables:
- users
- attendance

The exported SQL database file is included in this folder.

## 8. Installation Requirements
To run the application locally:
1. Install WAMP Server.
2. Place the project folder inside the WAMP www directory.
3. Import the supplied SQL file into phpMyAdmin.
4. Configure the database connection in db.php.
5. Start Apache and MySQL services.
6. Open the application through localhost in a web browser.

## 9. Project Status
The application has been implemented, deployed online and tested. Login, attendance recording and attendance record viewing have been verified.

## 10. Project Purpose
The system aims to reduce the difficulties associated with manual attendance recording and provide a centralised digital method of storing and accessing church worship service attendance information.
